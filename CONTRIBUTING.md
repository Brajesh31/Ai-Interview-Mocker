# Contributing

Read the README and understand the Next.js, Clerk, Gemini, and Drizzle boundaries before changing code.

1. Create a focused branch.
2. Run `npm ci`.
3. Keep credentials in local environment files.
4. Validate authentication, AI failure, database failure, empty states, and responsive UI behavior.
5. Run `npm run lint` and `npm run build`.

Pull requests should describe user-visible behavior, schema or API changes, validation performed, and any security or privacy implications.
