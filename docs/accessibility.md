# Accessibility expectations

New and modified interface elements should:
- Use native buttons for actions and links for navigation.
- Associate every form control with a visible programmatic label.
- Preserve keyboard operation and visible focus indicators.
- Expose loading and error messages to assistive technology.
- Give icon-only controls meaningful accessible names.
- Avoid using color as the only way to communicate status.
- Keep dialogs keyboard accessible and prevent accidental dismissal during active submissions.

Before release, test key flows with keyboard-only navigation and at least one screen reader.
